# PCB design guide (KiCad + MCP handoff)

Project: LED sun, Ø1773 mm disc · concentric rings, 12 wedges + centre disc · SK6812 RGBW @ 30 mm pitch · 2416 LEDs on 25 boards (3 unique designs) · PixLite E4-S Mk3.
Generated by Sun PCB Studio. Companion files: design.json (machine-readable), designs/*-outline.dxf, designs/*-placement.csv.

## Workflow

1. New KiCad project per design (A, B, C). Netlist per schematic-requirements.md.
2. Import the outline DXF to Edge.Cuts. Set origin to the DXF (0,0).
3. Script the placement from the CSV: footprint at (PosX, PosY), rotation Rot_deg, side top. LED footprint: 5050 4-pad (build from the SK6812RGBW datasheet; pad pitch verify against C5160656's EasyEDA footprint). 
4. Route data as the serpentine in the routing SVG (LED_k DOUT → LED_k+1 DIN, short direct hops; 0.25 mm track is fine).
5. Pour power per electrical-requirements.md; stitch vias at every LED.
6. DRC then export Gerbers + BOM + CPL for JLCPCB.

## Stackup & rules

- 2-layer FR4 1.6 mm, 2 oz outer copper, HASL or ENIG, any colour (black hides seams behind acrylic).
- Design rules: track/clearance ≥ 0.2/0.2 mm (JLC min 0.127); via ≥ 0.6/0.3 mm; keep everything ≥ 3 mm from Edge.Cuts (matches the LED keepout used by the layout).
- Panelisation: none — each board runs as its own JLCPCB PCBA order (largest 446 mm wide, inside the 460×500 envelope).
- Add 3 fiducials (1 mm pad / 3 mm mask) spread wide on the LED side of each design + 2 on the wire side if double-side assembly.

- Placement: `design-A-placement.csv` — PosX/PosY are board-local (origin = LED-bbox top-left, y down), Rot_deg is the footprint rotation (ring LEDs are tangent-aligned). Place with a script/MCP, do not hand-place 172 parts.

## Sanity checks before ordering

- [ ] LED count per design matches placement CSV (A=172, B=109, C=78).
- [ ] Chain order spot-check: LED1 at the REF small circle, serpentine matches routing SVG, last LED at the REF large circle.
- [ ] Outline DXF imported at 1:1 (measure a known radius).
- [ ] No part inside 3 mm edge keepout; no copper across Edge.Cuts.
- [ ] boards.csv rotation applied at install time, not in the PCB — all 25 boards use the 3 designs unmodified.
